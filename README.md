# Netrunner-Set-Editor

`/data` holds *Magic Set Editor* templates for editing custom *Android: Netrunner* cards:

* `data/netrunner.mse-game/*`
* `data/*.mse-style/*`: In *A:NR* (unlike *M:tG*), each card-type has its own unique frame.
* `data/*.mse-include`
* `fonts/*.{ttf,otf}`

* Frames: `/u/MNeMic`'s high-resolution re-interpretations of *FFG* frames.
* Symbols (credit, click, trash, etc): Both *FFG* & *NSG* symbols.
* Fonts: 

    * Bank Gothic Medium
    * Trajan Pro Regular
    * Monkirta Pursuit NC
    * Gill Sans (& Bold)
    * Minion Pro (& Italic)
    * Arial (Narrow)

(NB. `netrunner_set_editor.exe` is just a renamed `MSE.exe` (`v2.6.3`), without any Magic/Yu-Gi-Oh/Pokemon/etc `data/`-files.)
